# promo-versioning-automation-LangChain-RAG-assistant
A Retrieval-Augmented Generation (RAG) assistant that answers questions about the [AE Promo Versioning Pipeline] (https://github.com/prasadpradhan/ae-promo-versioning) — a CSV-driven broadcast automation system for Adobe After Effects.  Built with LangChain, ChromaDB, and Claude (Anthropic API).
